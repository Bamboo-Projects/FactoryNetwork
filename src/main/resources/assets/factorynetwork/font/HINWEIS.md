# JetBrains Mono

`jetbrains_mono.ttf` und `jetbrains_mono_bold.ttf` sind JetBrains Mono,
veröffentlicht unter der SIL Open Font License 1.1.

Die Lizenz verlangt, dass ihr Text mitgeliefert wird. **Er fehlt hier noch** —
vor der ersten Veröffentlichung muss `OFL.txt` aus dem Projekt danebenliegen:
<https://github.com/JetBrains/JetBrainsMono/blob/master/OFL.txt>

Die Schrift wird nur im Terminal verwendet. Alles andere — Spielerinventar,
Jade, Meldungen im Chat — bleibt bei Minecrafts eigener Schrift.
