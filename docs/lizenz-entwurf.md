# Lizenz — Entwurf, nicht in Kraft

`gradle.properties` sagt seit jeher `mod_license=MIT`, aber es gibt keine
`LICENSE`-Datei. Der Text dafür steht hier fertig.

**Warum er hier steht und nicht dort:** Eine Lizenzdatei ist eine
rechtsverbindliche Erklärung, und drei Angaben darin trifft nur der
Rechteinhaber selbst — wessen Name im Copyright steht, ob überhaupt ein
Klarname, und welches Jahr. Der Name unten stammt aus der Git-Identität; das
ist eine Vermutung und keine Entscheidung.

**Wenn er stimmt:** Datei nach `LICENSE` im Wurzelverzeichnis kopieren, den
Kopf (`# Lizenz — Entwurf …` bis hierher) entfernen, committen.

MIT verträgt sich mit GuideMEs LGPL-3.0 — eine Abhängigkeit, kein
eingebetteter Code.
