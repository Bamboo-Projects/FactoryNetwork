# Doku der Web-Runtime

Die Runtime ist seit September 2026 die eigene Mod **BambooCEF**. Ihre
Pläne, Messberichte und die Grenze zwischen Runtime und IDE liegen jetzt in
deren Repo: https://github.com/Bamboo-Projects/BambooCEFMC/tree/master/docs

Hier bleiben nur die Dokumente, die FactoryNetwork als Nutzer der API
betreffen: der Editor (`stand-monaco.md`, `handpruefung-monaco.md`,
`ide-offene-punkte.md`) und der Weg der Trennung (`plan-split-bamboocef.md`).
